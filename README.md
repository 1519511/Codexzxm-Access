# Codexzxm Private Preview Access

This public repository is only an access gateway for invited testers. It does not contain Codexzxm source code.

If the repository owner sent you a one-time claim link:

1. Sign in to your own GitHub account.
2. Open the claim link.
3. Do not edit the prefilled claim token.
4. Submit the issue once.
5. Wait for the workflow comment confirming that a private-repository invitation was sent.
6. Accept the GitHub invitation to `1519511/Codexzxm`.
7. Open the latest private prerelease and give the private repository/release URL to Codex for installation.

A claim link is single-use. If it reports expired/invalid, ask the owner for a new link.

Security note: `1519511/Codexzxm` is a private repository owned by a personal GitHub account. GitHub personal repositories grant collaborators write access, not read-only access. The main branch is protected separately; invited testers should treat the repository as read-only and use it only for installation/testing.
